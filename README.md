# 呼称課題アプリ NamingApp v1.0

画像呼称課題を実施するためのWindowsアプリケーションです。

製作者：宇杉竜一

## 対象

呼称課題を実施する利用者、検査者、研究者

## 主な機能

- 刺激画像を番号順に提示
- 画像提示後からの音声録音
- 音声閾値に基づく反応時間の記録
- Whisperによる日本語音声認識
- 正誤判定
- 同義語設定ファイルによる正解判定の調整
- 録音ファイルおよび結果テキストの保存
- 15秒タイムアウト

## 配布版の入手

Windows用の配布版は、GitHub ReleasesからZIPファイルをダウンロードしてください。

ZIPファイルを展開後、`run_naming.bat` をダブルクリックして起動します。

## フォルダ構成

```text
NamingApp
├── NamingApp.exe
├── _internal
├── ffmpeg.exe
├── synonyms.json
├── images
│   └── Naming
├── whisper_model
├── results
└── run_naming.bat
```

`_internal`、`ffmpeg.exe`、`whisper_model` は動作に必要です。削除、改名、移動しないでください。

## 刺激画像

刺激画像は `images/Naming` に入れます。

ファイル名は次の形式にしてください。

```text
番号_正解語.拡張子
```

例：

```text
1_りんご.jpg
2_ぶどう.jpg
3_みかん.png
```

使用できる画像形式は `.jpg`、`.jpeg`、`.png` です。画像は先頭の番号順に提示されます。

## 同義語設定

`synonyms.json` を編集すると、別名も正解として扱えます。

```json
{
  "りんご": ["アップル"],
  "自動車": ["車", "くるま"]
}
```

画像が `10_自動車.jpg` の場合、JSONの左側には `自動車` を設定します。

## 実施方法

1. マイクを接続し、Windowsのサウンド設定で入力レベルが動くことを確認します。
2. `run_naming.bat` をダブルクリックします。
3. 被験者IDと氏名または匿名化IDを入力します。
4. 試行開始画面で検査者がEnterキーを押します。
5. 対象者が画像名を発話します。
6. 発話後、検査者がEnterキーを押して次の試行へ進みます。

## 録音・反応時間・タイムアウト

音声は画像提示後からEnterキーが押されるまで連続して取得されます。

反応時間は、画像提示後に音量が設定閾値を最初に超えた時点として記録されます。

タイムアウトは、画像提示後15秒が経過してもEnterキーが押されなかった場合です。音量閾値を超えたかどうかは、タイムアウト条件ではありません。

## 結果

結果は `results` フォルダ内に、被験者別・測定日時別のフォルダとして保存されます。

主な出力ファイル：

```text
voice_01_りんご.wav
voice_01_りんご_timeout.wav
Naming_..._naming_results.txt
```
